# Agentic Storage Wiki

This wiki explains **agentic storage** in simple, practical terms.

**Agentic storage** is persistent, agent-aware storage for autonomous AI systems. It gives AI agents a durable place to store work products, state, artifacts, logs, and knowledge, while protecting the organization with safety controls.

## Why this wiki exists

Agentic AI systems are not just chatbots. They can take actions, write code, create playbooks, and operate across tools. But the LLM behind them is stateless: its “memory” lives in a temporary context window.

Agentic storage solves the persistence problem and adds the safety controls needed when autonomous agents interact with real storage systems.
